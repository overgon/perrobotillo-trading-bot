## 💡 **LECCONES APRENDIDAS**

1. **Auto-repair no debe enmascarar problemas de protección**
   - CLOSED_EMERGENCY requiere revisión humana
   - CLOSED_MANUAL es decisión del usuario
   - Solo cierres técnicos (TP, SL, Trailing) son auto-resetables

2. **Validaciones críticas en emergency close**
   - Siempre verificar `&& daily_loss > 0`
   - Portfolio calculation puede fallar y dar $0.00
   - $0.00 >= $0.00 = TRUE → emergency close incorrecto

3. **Slot-level detection es esencial**
   - Global status check no detecta slots individuales
   - 10 min threshold da +480% disponibilidad vs 2 horas

4. **Mantener USDT mínimo para operar**
   - Mínimo recomendado: $50-100 USDT
   - Con $0 USDT el bot no puede operar aunque haya señales
