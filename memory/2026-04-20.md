### **🐛 BUG EN TABLA DE TRADES:**

**Problema:**
- ❌ Campos `coin` y `slot` aparecían como `null`
- ❌ Tabla duplicada (una con nulls, otra correcta)

**Root cause:**
- El JSON de state files usa `slotId` no `slot`
- No hay campo `coin` en el JSON (hay que pasarlo como variable)
- Script original de scalping (`crypto-daily-report-v3.sh`) genera una tabla
- Nuestro script agregaba otra tabla al mismo archivo (append)

**Solución:**
- ✅ Cambiar `.slot` → `.slotId` en jq
- ✅ Pasar coin como variable: `--arg coin "$coin"`
- ✅ Reescribir archivo desde cero (no append)
